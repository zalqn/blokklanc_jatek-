# Blokklánc-játék

Indítás: `npm start` → http://localhost:3100

- `public/index.html` – a játék (PeerJS, telefonok csatlakoznak a kivetítőhöz)
- `server.js` – kiszolgálja a játékot + `/api/prices` (BTC/ETH/XRP valódi árfolyam, CoinGecko, tartalék Binance, 15 mp cache)

Deploy: Render Web Service (render.yaml).
